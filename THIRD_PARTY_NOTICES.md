## Runtime dependencies (fetched by Gradle, not vendored)

None of these are stored in this repository. They are resolved at build time
from the repositories declared in `settings.gradle` and `build.gradle`, so a
clean checkout reproduces them from their official sources.

| Component | Why | Licence |
| --- | --- | --- |
| Minecraft `com.mojang:minecraft:1.21.11` | the game itself, compile only, never redistributed | Mojang EULA |
| Yarn mappings `net.fabricmc:yarn` | the only mappings used; every source uses Yarn names | CC0-1.0 |
| Fabric Loader `net.fabricmc:fabric-loader:0.19.3` | mod loading, entry points | Apache-2.0 |
| Fabric API `net.fabricmc.fabric-api:fabric-api` | client tick, key bindings, client commands, connection events | Apache-2.0 |
| Fabric Loom (Gradle plugin) | remapping and jar production | Apache-2.0 |
| Brigadier (`com.mojang.brigadier`) | command tree, via Minecraft | MIT |
| SLF4J API | logging facade, via Fabric Loader | MIT |
| LWJGL / GLFW | key constants only (`GLFW_KEY_RIGHT_SHIFT`, `GLFW_KEY_RIGHT_CONTROL`) | BSD-3 / zlib |

No Minecraft or Fabric binary is committed to this repository or shipped inside
the source archive.

## Bundled assets

* `src/main/resources/assets/chatmacro_studio/icon.png` — a 128×128 icon drawn
  for this project (dark slate rounded square, blue speech bubble, three dots,
  a small red square). It is original, contains no third-party art and no
  Mojang or Minecraft branding. MIT, same as the project.
* `src/main/resources/assets/chatmacro_studio/lang/en_us.json`, `tr_tr.json` —
  written for this project.

No third-party UI pack, icon set, font or texture is used. Every panel, border,
shadow and rounded corner is drawn with plain `DrawContext` fills from the
semantic tokens in `dev.chatmacro.studio.theme`.

## Development-only tooling

`tools/offline-javac/` is a build harness, not part of the mod. It is never
referenced by `build.gradle` and never ends up in the jar.

| File | Origin | Licence |
| --- | --- | --- |
| `tools/offline-javac/vendor/java-compiler-runtime.mjs` | TeaVM, via `wasm-oj/forge` | Apache-2.0 (© 2024 Alexey Andreev), header preserved |
| `tools/offline-javac/vendor/java-compiler-bindings.mjs` | generated by the TeaVM compiler | Apache-2.0 |
| `tools/offline-javac/jw.mjs` | written for this project | MIT |

The compiler and class libraries it loads are **not** in this repository; they
come from the npm package `@wasm-oj/toolchain-java@0.2.0`
(OpenJDK 21 `javac` compiled to WebAssembly with TeaVM 0.13.1). See
`tools/offline-javac/vendor/NOTICE` for the SHA-256 values that were checked
against that package's own manifest, and
`tools/offline-javac/README.md` for the setup command.

Gradle 8.14.2 and its wrapper jar are likewise not vendored; `BUILD.md` explains
how to install the official, checksum-verified wrapper.

## What is deliberately absent

* no analytics, telemetry, crash reporter or updater library;
* no HTTP client, no JSON-RPC, no WebSocket, no Discord/Telegram bridge;
* no obfuscation, string encryption or packer;
* no copied branding, logos or assets from Mojang, Microsoft or any server
  network.
